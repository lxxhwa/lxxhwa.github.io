1. 목적

yuha-uploader는 채널 운영자 본인이 만든 영상을 본인 YouTube 채널 등에 업로드하는 개인용 도구입니다.

Google 계정 인증 후 YouTube Data API를 통해 운영자 본인 채널에 영상을 업로드하고, 채널 이름을 확인하는 데에만 사용합니다. 다른 사람의 정보는 수집하지 않습니다.

인증 토큰은 운영자의 비공개 작업 환경에만 저장되며, 제3자에게 판매하거나 공유하지 않습니다.

4. 권한 철회

언제든 https://myaccount.google.com/permissions 에서 접근 권한을 삭제할 수 있습니다.

5. Google API 데이터 사용
